# AI Chatbot With Memory

A simple command-line AI chatbot built with Python and Groq.

The chatbot maintains conversation history and remembers the last 5 messages during the current session.

## Features

- Groq LLM integration
- CLI-based chatbot
- Conversation memory
- Remembers the last 5 messages
- System personality
- Secure API key using `.env`
- Error handling
- Exit command

## Technologies

- Python
- Groq API
- Groq Python SDK
- python-dotenv
